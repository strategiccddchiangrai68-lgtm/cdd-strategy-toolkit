# CDD Strategy Toolkit — เตรียมข้อมูลแผนพัฒนาตำบล

เว็บแอปช่วยพัฒนากรจัดทำแผนพัฒนาตำบลตามแบบฟอร์มรูปเล่มของกรมการพัฒนาชุมชน
ตั้งแต่ทบทวนแผนเดิม ข้อมูล TIS วิเคราะห์ SWOT/TOWS โครงการ จนถึงส่งออกรูปเล่ม .docx

- ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์ของผู้ใช้ ไม่ถูกส่งไปที่ใด ทำได้หลายตำบลในเครื่องเดียว และบันทึกเป็นไฟล์ .json เพื่อทำต่อเครื่องอื่น
- ใช้ AI ภายนอก (Gemini) แบบคัดลอกคำสั่งไปวาง แล้วนำคำตอบกลับมาให้แอปตรวจ
- สถานะ: ต้นแบบ ยังไม่ได้ทดสอบกับพัฒนากรในพื้นที่จริง

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `src/` | โค้ดต้นฉบับ แยกไฟล์ตามขั้น (แก้ที่นี่) |
| `docs/index.html` | ไฟล์เดียวที่ได้จาก build ใช้เป็นหน้าเว็บบน GitHub Pages (ห้ามแก้ตรง) |
| `build.js` | รวม `src/` เป็น `docs/index.html` |
| `tests/` | ทดสอบทั้งระบบด้วย jsdom และข้อมูลจริงของตำบลป่าแดด |
| `fixtures/` | ข้อมูลทดสอบ (ไฟล์ที่มีข้อมูลส่วนบุคคลอยู่ใน `fixtures/private/` ซึ่งไม่ขึ้น repo) |

## พัฒนา

```bash
npm install
npm run build   # สร้าง docs/index.html
npm test        # ต้องผ่านก่อน commit (ล้มถ้า docs/ ไม่ตรงกับ src/)
```

รายละเอียดการออกแบบและข้อตัดสินใจทั้งหมดอยู่ใน `CLAUDE.md`
