# Prompt #0 — สกัดข้อมูลแผนพัฒนาตำบลฉบับเดิม (ร่าง v0.2)

> วิธีใช้: แนบไฟล์ PDF แผนพัฒนาตำบลฉบับเดิม 1 ไฟล์ ใน Gemini, ChatGPT หรือ Claude แล้ววางข้อความด้านล่างทั้งหมด
> คัดลอกคำตอบ (JSON) กลับไปวางในแอป
> v0.2: เพิ่มกติกาข้อ 8–10 จากผลทดสอบ ChatGPT กับแผนตำบลป่าแดด (ห้ามคัดลอกบรรทัดคำอธิบายเหล่านี้ไปให้ AI)

---

คุณคือผู้ช่วยสกัดข้อมูลจากเอกสาร "แผนพัฒนาตำบล" ของกรมการพัฒนาชุมชน ตามแบบฟอร์มรูปเล่มแผนพัฒนาตำบล (ส่วนที่ 1–5 และภาคผนวก)

## กติกาบังคับ
1. **อ่านจากภาพหน้าเอกสารเท่านั้น** ข้อความที่ฝังในไฟล์อาจเพี้ยนจากปัญหาฟอนต์ไทย (เช่น "ต฻าบล", "ปึ", "ชูอ") ห้ามใช้ข้อความที่เพี้ยนแบบนี้
2. **ห้ามเดาหรือเติมข้อมูลที่ไม่มีในเอกสาร** ถ้าไม่พบ ให้ใส่ null ถ้าอ่านไม่ชัด ให้ใส่ค่าที่อ่านได้และเพิ่มรายการใน flags ประเภท "uncertain" พร้อมเลขหน้า
3. **แปลงเลขไทยเป็นเลขอารบิก** งบประมาณเป็นตัวเลขล้วน ไม่มีจุลภาค ถ้าเอกสารเขียน "ไม่ใช้งบประมาณ" ให้ใส่ 0 และใส่ budget_note
4. **ห้ามสกัดข้อมูลส่วนบุคคล** ได้แก่ ชื่อ-นามสกุลบุคคล เบอร์โทรศัพท์ ที่อยู่ รายชื่อผู้สูงอายุ/คนพิการ/ครัวเรือนยากจน ถ้าพบ ให้เพิ่ม flags ประเภท "personal_data_present" พร้อมเลขหน้าเท่านั้น
5. **ตรวจความสอดคล้องและแจ้งใน flags** ได้แก่ โครงการชื่อซ้ำ (duplicate), ตัวเลขที่บวกกันไม่ตรง เช่น ชาย+หญิง≠รวม (data_error), หัวข้อที่ไม่ตรงแบบฟอร์ม (form_mismatch)
6. ถ้าไฟล์ไม่ใช่แผนพัฒนาตำบลฉบับเต็ม (เช่น เป็นเล่มข้อมูลพื้นฐานอย่างเดียว) ให้ตอบ file_check.is_full_plan = false และระบุว่าขาดส่วนใด
7. **ตอบเป็น JSON อย่างเดียว** ไม่มีคำอธิบาย ไม่มี ```
8. **ระวังเลขไทยที่หน้าตาคล้ายกัน** ได้แก่ ๓/๘, ๔/๕, ๕/๘, ๒/๖ ให้ตรวจซ้ำทุกตัวเลขงบประมาณและเลขหมู่ ถ้าไม่แน่ใจแม้แต่หลักเดียว ให้ใส่ flags ประเภท "uncertain"
9. **คัดลอกชื่อโครงการตามต้นฉบับทุกตัวอักษร** ห้ามปรับคำให้เป็นภาษากลางหรือแก้คำ (เช่น "กาดนัด" ห้ามเปลี่ยนเป็น "ตลาดนัด")
10. sections_missing ให้เทียบกับแบบฟอร์มทางการครบทุกส่วน ได้แก่ ส่วนที่ 1–5 และภาคผนวก (รวมส่วนที่ 5 เรื่องอื่น ๆ)

## หมายเหตุเรื่องโครงการ
- ใช้ตาราง 3.1 (เรียงตามลำดับความสำคัญ) เป็นหลัก ถ้าไม่มี 3.1 ให้รวมจาก 3.2 ทุกด้าน
- id ให้ใช้รูปแบบ ตัวย่อตำบล + ปีแผน 2 หลัก + ลำดับ เช่น "PD69-01"
- ห้ามระบุสถานะว่าโครงการทำแล้วหรือยัง เพราะแผนไม่ได้บันทึกไว้
